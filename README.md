# AP-Manual for Senran Kagura: Estival Versus
# Requirements
- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases)
- Senran Kagura Estival Versus ([Steam](https://store.steampowered.com/app/502800/SENRAN_KAGURA_ESTIVAL_VERSUS/))
- (Optional) DLC: [Dual Blooming Hearts](https://store.steampowered.com/app/588961/SENRAN_KAGURA_ESTIVAL_VERSUS__Dual_Blooming_Hearts/) (11 Missions), [Mission Pack](https://store.steampowered.com/app/588300/SENRAN_KAGURA_ESTIVAL_VERSUS__Mission_Pack/) (6 Missions)
- (Optional, Reccommended) Univseral Tracker
# Randomization
## Locations
- Clear a Mission
- Destroy Festival Platforms
## Items
- Skills & Abilities (Transformations + Secret Ninja Arts)
- Movesets (Guard, Aerial Rave, Double Jump)
- Playable Characters/Shinobis
- Field Items (Bombshells only)
- Festival Platforms
# Rules & Restrictions
- Starting off the Randomizer, you lose access to the following:
  - Guard, Aerial Rave, Double Jump
  - Shinobi Tranformation, Frantic Mode, Secret Ninja Arts (Level 1, Level 2, Ultimate)
  - All Playable Characters but one (chosen at random - maybe later choosable)
  - Bombshells
- Using Frantic Mode additionally requires Guard
- Characters that can use Secret Ninja Arts without Transforming (such as Ikki Tosen Characters or Sayuri) don't need "Shinobi Transformation" to be able to use them.
- Missions where you have team mates in your own team, require having those characters unlocked
- When you receive a Death Link, you must restart the mission or choose a new one
- You send a Death Link when you fail the mission/run out of HP
- To "Clear" a mission, it must be beat with the assigned character
- To destroy Festival Platforms, you may use any unlocked character, as long as you have access to the corresponding mission
- Due to the nature of a manual, "Shinobi Girl's Heart"-Missions require Festival Platforms to be broken. For these you require Festival Platforms as Items to unlock them, but also to be able to break them. You can either break them early in the story mode, or use a different save, that has those missions already unlocked.
- "Shinobi Girl's Heart"-Missions can be clared in any order. Though, depending on your save, you might be required to beat them in order anyways
